Remote Server Assessment (Agentless Network Inspection) MILESTONE 4 ROADMAP
Assess internet-facing or internal server perimeters without installing software on the target host. Evaluates safely observable network attributes, open ports, TLS/SSL configuration, HTTP security headers, and administrative exposure.
Non-destructive probes • Anti-SSRF enforcement • Rate-limited
Critical Architectural Distinction: Network Assessment vs Operating System Audit
An IP address or hostname alone cannot provide a complete operating-system security audit. Agentless results are classified strictly as a Network Assessment. Observable network headers and port states cannot reliably determine internal OS user accounts, file permissions, installed package CVEs, or kernel parameters. Full OS auditing requires local execution or enrolled OpenAudit agents.
Enrolled Server Fleet Management MILESTONES 5 & 6 ROADMAP
Continuous and scheduled server auditing powered by lightweight, securely enrolled OpenAudit agents on Linux and Windows servers. Agents execute local audits using the shared Rust engine and cryptographically sign results back to the control plane.
